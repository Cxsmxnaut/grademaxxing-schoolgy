# Grademaxxing independent evaluation kit

This is a prepared reference pack for an evaluator. It has not been sent to anyone and is not an endorsement or claim of school approval.

Grademaxxing is an independent, read-only StudentVUE companion. Its public tools let a visitor estimate assignment impact, fixed-weight final targets, weighted grades and policy-configured GPA without signing in. Its fictional demo is available at `/demo`. A connected session can read records supported by the relevant district portal; simulations do not modify official school data.

## Evidence to review

1. Try `/calculators/assignment-impact`, including a new zero versus replacement of an existing score. Choose total points or weighted points-based categories explicitly.
2. Check `/methodology/calculator-validation` against the formulas in `/methodology/grade-calculations`. The examples use fictional inputs and do not claim every school uses these models.
3. Compare a standalone final worth a fixed course percentage with a test added inside a category. The category weight is not automatically the assignment's overall contribution.
4. Inspect `/privacy`, `/about` and `/studentvue-compatibility`. Grademaxxing uses server-assisted sign-in; avoid repeating a browser-to-district-only claim. Do not test a real student account without appropriate permission.
5. Treat GPA as an estimate using the configured policy; the connected application's current PUSD policy is provisional, not an official transcript calculation.

## Questions for an independent assessment

- Can the public tool reproduce the supplied ordinary and impossible-target examples?
- Are its model selection, required inputs, exclusions and rounding understandable?
- Does it remain usable with a phone and keyboard, and are errors clear?
- Which features or authentication configurations did you actually test?
- What limitations or alternatives should a reader know?

An evaluator is free to decide whether to mention the product and how to describe limitations. A self-published comparison or copied release announcement should not be presented as independent validation. Do not fabricate testimonials, ratings, adoption statistics, authors, district support or grade-improvement claims.

Public reference links should use the canonical production origin. Verify current release availability before sharing. The source and license attribution are preserved in the repository; security reports should omit credentials and school records.
